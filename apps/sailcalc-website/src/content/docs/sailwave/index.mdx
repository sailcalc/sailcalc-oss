## The SailCalc "effect" for SailWave

It is only possible to modify Sailwave's output in limited ways, but it is
possible to use "effects". A Sailwave effect is code that is added to the output
file and was originally used for simple things like adding a "hover" effect
(hence the name), but can also be used to rewrite whole sections of the document
like making tables sortable.
