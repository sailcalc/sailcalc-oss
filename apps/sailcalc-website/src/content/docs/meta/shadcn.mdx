## Modifications

### Spinner

- `IconLoader` replaced with `IconLoader2` as it is nicer.
- added `spin` property (default `true`) to stop spinning.

```ts
let {
	…
	spin = true,
}: SVGAttributes<SVGSVGElement> & {spin?: boolean} = $props();
</script>

<IconLoader2
	…
	class={cn('size-4', spin && 'animate-spin', className)}
	…
/>
```
